# Listening pack

Play each clip once. Write down every quantity, unit, reagent name and
container identifier you hear, exactly as you heard it. Do not replay a
clip, and do not guess a value you did not hear: leave it blank.

The clips are in random order and half of them are in noise. Nothing in
the file names says which is which.

Answers go in one file per listener, as `<clip number>: <what you heard>`.
